# ABC社 スマートホームデバイス ユーザーマニュアル

## 製品概要

ABC社のスマートホームデバイス「SmartHub X1」は、家庭内の様々なIoTデバイスを統合管理するためのハブデバイスです。

### 製品仕様

| 項目 | 仕様 |
|------|------|
| モデル名 | SmartHub X1 |
| 寸法 | 120mm x 120mm x 35mm |
| 重量 | 280g |
| 対応プロトコル | Wi-Fi 6, Bluetooth 5.0, Zigbee 3.0, Thread |
| 非対応プロトコル | Z-Wave, Matter（将来対応予定） |
| 電源 | DC 5V/2A (USB-C) |
| 対応デバイス数 | 最大100台 |
| 動作温度 | 0°C〜40°C |

## セットアップ手順

### 1. 初期設定

1. SmartHub X1をコンセントに接続します
2. 本体のLEDが青色に点滅するまで約30秒待ちます
3. スマートフォンに「SmartHub」アプリをダウンロードします
4. アプリを起動し、画面の指示に従ってWi-Fi設定を行います

### 2. デバイスの追加

1. アプリのホーム画面で「デバイス追加」をタップします
2. 追加したいデバイスの種類を選択します
3. デバイスをペアリングモードにします
4. 自動検出されたデバイスを選択して追加完了です

## トラブルシューティング

### Wi-Fi接続ができない場合
1. ルーターを再起動してください
2. SmartHub X1を工場出荷設定にリセット（本体裏面のリセットボタンを10秒長押し）
3. 再度セットアップを行ってください

### デバイスが検出されない場合
対象デバイスがSmartHub X1の対応プロトコル（Zigbee 3.0, Thread）に対応しているか確認してください。
